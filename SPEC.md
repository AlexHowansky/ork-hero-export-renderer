# HERO Export Renderer

You are a JavaScript and TypeScript expert. You are designing a new TypeScript
library. This document explains the requirements that must be adhered to.

## Architecture & Design

* Target Bun as a runtime, but don't explicitly exclude Node.

* Observe OWASP Top Ten guidelines.

* Observe best practices for modern development.

* All error messages should be user-friendly.

* Implement consistent logging to aid debugging.

## HERO System

This library will generate HTML character sheets for the HERO System role
playing game. The user will input two files and you will output one file. This
output should be written to a file, printed to stdout, or generated as a string.

### HERO Designer

* The user will use an existing, separate app called `HERO Designer` to design
  and build their characters. This app generates `*.hdc` files, which contain
  XML. We will call these "character files". These files contain all the
  information we need to know about a game character.

* `@fixtures/HD6.jar` contains the compiled version of the `HERO Designer` app.
  You may be able to use it to extract any needed information.

* See `@fixtures/HDDocs.pdf` for the `HERO Designer` app documentation. The
  section titled `EXPORT FORMATS` contains a description of the mechanism used
  to apply an export template to a character file.

### Export Templates

* The `HERO Designer` app allows the user to export a `*.hdc` character to a
  `*.html` file for printing or generic use. This export process is shaped by
  export templates, which are HTML files with special comment tags that get
  replaced by data from the `*.hdc` character file. These export templates are
  named `*.hde`. Thus, the `HERO Designer` app applies a `*.hde` export template
  to a `*.hdc` character file in order to produce a `*.html` character sheet.
  It is this specific feature that we are going to duplicate. There are no UI
  components at all to this app.

* See `@fixtures/Redshift.hdc` for an example of a character file.

* See `@fixtures/Ork-16x9.hde` for an example of a template file.

* See `@fixtures/Redshift.html` for an example of a character sheet.

* The character sheet `@fixtures/Redshift.html` was generated by the
  `HERO Designer` app, from the character file `@fixtures/Redshift.hdc` using
  the export template `@fixtures/Ork-16x9.hde`. You can use these files to
  design tests. Our goal is to generate pure TypeScript that can precisely
  recreate the `@fixtures/Redshift.html` file.

## Features

There are two primary features that you need to create.

* Create a self-contained TypeScript library that can be used to take a `*.hdc`
  file and a `*.hde` file, and generate a `*.html` file from them. Package this
  so that other Bun/Node apps can cleanly import it and use the generation
  feature.

* Create a CLI utility that uses this library. It should take two required
  arguments: the `*.hdc` file and the `*.hde` file. It should take a third
  optional argument for the output `*.html` file. If the output file is not
  specified, it should output to stdout.
